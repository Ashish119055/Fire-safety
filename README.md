# ITI અગ્નિ સુરક્ષા સિમ્યુલેટર (Fire Safety Simulator)

ITI તાલીમાર્થીઓ માટે ઇન્ટરેક્ટિવ ફાયર સેફ્ટી તાલીમ — એક જ ફાઇલ (`index.html`), કોઈ ઇન્સ્ટોલેશન નહીં.

## કેવી રીતે ચલાવવું
`index.html` ને Chrome / Edge માં ખોલો (ડબલ-ક્લિક). પ્રોજેક્ટર પર બતાવવા "ફુલ સ્ક્રીન" બટન દબાવો.
ઇન્ટરનેટ વગર પણ ચાલે છે (ફક્ત ફોન્ટ ઓનલાઇન લોડ થાય, ન મળે તો સિસ્ટમ ફોન્ટ વપરાય).

## મોડ્યુલ
1. **હોમ** — ઇન્ટરેક્ટિવ ફાયર ટ્રાયેંગલ, R.A.C.E., ઇમરજન્સી નંબર
2. **આગના પ્રકાર** — Class A, B, C, D, E, F/K
3. **એક્સટીંગ્વિશર** — 7 પ્રકાર, ભાગોનો ડાયાગ્રામ, સરખામણી ચાર્ટ, પ્રેશર ગેજ
4. **લાઇવ સિમ્યુલેટર** — 6 આગના દ્રશ્ય, P.A.S.S. પદ્ધતિથી માઉસ/ટચ વડે આગ બુઝાવો; ખોટા એક્સટીંગ્વિશરનું પરિણામ
5. **ફાયર એલાર્મ** — MCP કાચ તોડો, સ્મોક ડિટેક્ટર, કંટ્રોલ પેનલ, સાયરન, ફાયર ડ્રિલ
6. **ફાયર બકેટ** — રેતી કે પાણી? રમત
7. **ફાયર એક્ઝિટ પ્લાન** — ITI બિલ્ડિંગ નકશો, ફેલાતી આગ, સુરક્ષિત રસ્તો અને એસેમ્બલી પોઈન્ટ
8. **ક્વિઝ + પ્રમાણપત્ર** — 10 પ્રશ્નો, તાલીમાર્થીના નામે પ્રમાણપત્ર
